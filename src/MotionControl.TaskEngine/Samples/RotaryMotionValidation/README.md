# 十三轴双夹位运动验证

这是独立的软件设备样例，以双夹位旋转台、焊接、压合、缓存、视觉和分拣动作验证十三轴与多工位协作。它不配置扫码 IO、不生成产品编号，也没有逐件记录步骤；占料、夹位位置、加工结果和各机构反馈仍参与工艺条件。原有 `RotaryWelding` 扫码和记录样例保留，已启用该工艺的设备不得静默切换。

任务与设备变量使用独立的 `RotaryMotion` 前缀，以免覆盖原样例。上料、旋转台、焊接、压合和复检分拣顺序及共享区域沿用原样例；转台仍只在 -90° 和 +90° 切换。不同工位可并行，同工位轴动作按明确顺序执行；动作前检查不是连续安全互锁。

`NewRotaryTestConfiguration.ps1 -MotionOnly` 仅生成新的隔离配置，可通过 `-ExecutionOwner TaskEngine` 或 `-ExecutionOwner StationFlows` 明确选择任务列表或 C#。它不会覆盖既有 Machine01、草稿和恢复文件。`StartRotaryWelding.ps1` 识别隔离配置中的纯运动标记，不建立扫码设备规则；设备状态模型、轴和必要反馈仍独立工作。C# 样例的载具令牌只用于同一会话区分交接，不表示扫码结果，现场证据继续独立保存。

13 轴、DI/DO 和位置均为软件测试布局；物理接线、机械干涉、安全回路、真实卡和现场回零条件需要另行验证。执行前在正式 Host 核对连接、伺服和回零；故障、暂停及结束时保留必要状态，不能通过清空数据绕开未确认的设备区域。
