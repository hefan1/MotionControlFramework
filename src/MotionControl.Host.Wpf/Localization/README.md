# 界面多语言

## 当前语言

- 支持简体中文（`zh-CN`）和英文（`en-US`），程序启动时默认简体中文。
- 主窗口底部的语言选择框会立即切换界面文字，不需要重启；切换时保留当前一级和二级导航位置。
- 英文资源字典合并简体中文字典作为回退。英文缺项时继续显示中文，不会出现空白。

## 文件位置

- `Strings.zh-CN.xaml`：中文默认文字，也是资源键的来源。
- `Strings.en-US.xaml`：英文文字；缺少英文项时沿用中文。

资源键使用中文界面原文。例如，`设备总览` 既是中文显示文字，也是搜索键。中文开发者可以在 XAML、C# 和资源文件中直接搜索这个词。

## 添加或修改界面文字

1. 先在 `Strings.zh-CN.xaml` 增加一条中文键和值。
2. 在 `Strings.en-US.xaml` 使用相同的中文键补上英文值。
3. XAML 控件使用 `{DynamicResource 中文原文}`；代码生成的导航文字使用 `GetLocalizedText("中文原文")`。
4. 当前文件只覆盖上位机外壳文字。后续具体页面增加时，由对应页面/模块维护自己的语言资源，不把全部页面翻译堆进主窗口或一个不断膨胀的文件。

同一个中文文字如果表达不同含义，使用不同的资源键，例如 `用户管理` 和 `当前用户`。ResourceDictionary 中不能出现重复键。

语言切换只影响界面显示文字。轴名、IO 名、配置键、日志字段、通讯协议内容和 MES 字段属于设备或数据定义，不应因为界面语言变化而改名。代码中新增的界面显示文字应使用资源键；资源键保留中文原文，方便中文开发者按界面文字快速搜索。
