# 任务配置与列表编辑初版

## 如何打开

- 正常 Host：设置 → 任务配置。现有轴映射、轴手动、IO、变量页的基本布局不改。
- 独立预览：`MotionControl.Host.Wpf.exe --task-editing-preview`。窗口使用 `%LOCALAPPDATA%/MotionControlFramework/TaskEditingPreview/TaskEditorPreview` 的独立示例配置，不创建正常 Host 的控制卡、IO 或设备恢复服务。

工位安排和任务库是同页两个页签。编辑任务时，工作区切为步骤树和分类详情，并隐藏外层重复的保存/检查工具栏。返回后保留设备草稿。无问题时收起空检查表，避免占用参数区域。

按 PDF 四页方案，工位表增加“设备文件版本”和行内编辑；任务库展示已应用文件版本与草稿/检查状态。它们不代表已冻结运行会话的修订号。编辑器按步号、动作、类型分栏，整行高亮；结构根的移动/复制/删除按钮按实际能力禁用。多轴步骤提供目标摘要表，选择一根轴后在下方设置它的独立速度、加减速度与目标；表格只读，动作不会试跑。未保存标记显示在工具栏。

## 推荐操作

1. 在任务库新增、复制或导入任务，选中后编辑。任务显示名称可以修改，稳定 TaskId 不因改名而改变。
2. 选中顺序段新增动作；选中并行段新增顺序分支；条件分支下选中成立/不成立顺序段后新增动作。
3. 选中不同步骤后，右侧显示对应的运动、信号、变量、条件或资源字段。轴、IO、变量和点位均来自当前设备目录。
4. 保存草稿。此操作允许保留尚未填完的业务引用，不改变任何运行文件。
5. 配置工位、任务、运行方式和握手变量；检查后双击问题定位任务和步骤。
6. 在满足应用条件后确认应用。每份内容变化的运行定义自动增加修订号；没有变化不重复递增。

顶部原整机按钮的语义不改。此页不运动、不使能、不回零、不写 IO 或变量运行值。回零步骤引用已有轴配置，不暴露厂商模式编号。

## 草稿与运行文件

- `Drafts/TaskWorkspace.json`：单个设备的完整草稿包，包含任务和工位清单。讨论稿原建议分别保存多个草稿文件，初版改为单包原子保存，防止半保存。
- `Tasks/*.json`、`Parameters/TaskMachine.json`：沿用原运行格式。
- `Drafts/TaskApplyPending.json`：应用过程恢复标记。存在时 `TaskMonitorSession.LoadMachine` 禁止加载半应用任务。
- `Backups/TaskApply-<GUID>/`：应用前原文件字节。保留现场历史，不递归清理。
- `Backups/TaskDraft-<GUID>.json`：人员确认放弃草稿时保存的副本。
- `Backups/TaskLocal-<GUID>.json`：点击“保留草稿副本”得到的本窗口完整内容，包含当前编辑器尚未保存的有效字段；不覆盖原草稿，不改变运行文件，不清除未保存标记。
- `Drafts/TaskWorkspace.lock`：跨编辑窗口写入锁文件，锁随文件句柄释放。

应用前两次检查来源签名及完整引用，写前备份所有受影响文件，写入失败按原字节回滚。意外退出后显示“恢复上次应用”入口；恢复前同样检查 Host 会话边界。若自动恢复本身失败，保留恢复标记和完整错误，不能把半应用任务当作正常配置打开。

草稿读入后保存一份只驻留内存的字节签名，不增加 JSON 字段。其他编辑窗口先保存，或外部程序修改、删除草稿后，旧窗口的保存和应用都会报出冲突。可先点击“保留草稿副本”，按页面显示路径找回自己的内容；返回任务配置后选择“载入最新草稿”并确认，读取公共草稿，不会删除他人的草稿。副本用于人工核对，当前没有自动合并或一键覆盖功能。

目录引用不区分大小写，列表会保留原引用拼写。空的全部/任一/取反条件在查看时保持为空，检查仍会报告错误；取反条件只允许一个子条件，删除后可再次添加。保存和切换语言按稳定 ID 保留当前工位与任务选择。

第一轮 Host 只有在任务仿真窗口已关闭、控制卡会话已断开时允许应用。草稿仍可随时保存。后续真实任务运行入口统一后，才把边界改为明确的任务会话结束与停稳状态；当前不把“已暂停”当作“可以换运行版本”。

## 明确边界

目录是在打开编辑器时读取的配置快照。其他页面修改映射、变量定义或点位后，检查/应用会发现来源变化，旧草稿不能直接覆盖；“重新载入运行文件”需要确认，并备份被放弃的草稿。

列表编辑不替代传统 C# 工位代码。条件使用已有比较、全部、任一和取反；没有脚本或通用 while 节点。直线插补仍未接入执行，新建选择禁用；已有定义只读保留。复杂既有条件超出表单能力时显示原因并保留原定义，不能使用默认值覆盖。

资源进入/退出检查不等于持续机械避让。工程权限认证、真实任务执行接入、全局运行变量共享和任务树跨进程恢复仍在后续阶段。

当前验证程序 `tools/MotionControl.TaskEditing.Checks` 只做真实临时文件、控件事件和离屏布局检查，不连接控制器，也不能代替实际桌面鼠标验收。
