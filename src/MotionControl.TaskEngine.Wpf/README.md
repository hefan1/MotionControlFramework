# 任务运行监控页

此项目提供 WPF 任务配置、编辑和运行监控，也提供独立内存示例。它引用 `MotionControl.TaskEngine`，不直接引用运动卡 SDK；正式 Host 负责装配设备任务会话。

## 页面入口

- Host 导航：`监控 → 任务接入状态`可读取已应用任务并创建任务会话，通过独立按钮复位、启动、暂停和停止。加载不会自动启动；设备任务的端到端运行仍需验证。
- 内存示例供开发验证，包括轴组定位、顺序/并行、条件分支、子任务、共享资源、DI 等待、DO 写入和设备变量赋值。
- 独立启动：Host 启动参数 `--task-simulation` 只打开内置内存示例，不初始化正常 Host 的卡连接服务。
- 内存示例默认不启动任务。先按窗口上的“复位”，再按“启动”。示例默认连续供料，并让夹紧到位 DI 在夹紧输出变化后延时反馈；底部“自动工艺信号”可关闭以手动检查等待条件。示例输入、输出和变量属于独立的 `InMemoryTaskDevice`。

## 步骤详情与现有页面

步骤树从任务定义建立；右侧详情同时显示定义参数和执行时采样，完成后的采样注明为历史记录。

- 轴定位、轴组和回零：显示任务引用的目标、工程单位、速度、加速度、控制卡标识。关联按钮跳到“轴映射配置”并选择对应逻辑轴，或跳到“轴手动”并滚动到该轴卡片。
- DI 等待和 DO 写入：显示逻辑名称、期望/写入值和采样状态。关联按钮区分 DI 与 DO，跳到“IO 映射”并选择对应行。
- 设备变量：显示现有变量名和 .NET 类型。关联按钮跳到“设备变量”并选择对应行。
- 示教点：从现有手动位置配置解析名称与位置，并提供轴映射和轴手动页面入口。
- 并行、分支和共享资源：按执行调用编号显示各子步骤；共享资源信息只描述逻辑占用和互锁，不能替代机械避让验证。

上述导航仅定位和选中现有页面条目。打开“轴手动”不会自动使能、回零或移动；打开“IO 映射”不会写输出。

## 配置与仿真边界

现有机器配置入口使用 `TaskResourceCatalogLoader` 读取轴映射、IO 映射、设备变量定义和示教点；任务配置也由当前设备目录加载。监控模块不会复制或自动创建第二份映射。

独立内存示例的轴位置、DI/DO 和变量值只属于示例设备。正式 Host 的任务入口使用设备运行时、逻辑轴、IO 和共享变量；目前 Host 的正运动连接只支持指定仿真控制器，任务运行链路尚未完成端到端验证。任务配置与列表编辑见 [Editing/README.md](Editing/README.md)。

## 主要文件

| 位置 | 内容 |
| --- | --- |
| `Monitoring/TaskStationRow.cs` | 工位表格行及整机状态文字 |
| `Monitoring/TaskStepTree.cs` | 任务定义与本轮执行调用的关联 |
| `Simulation/TaskMonitorSession.cs` | 配置目录加载与独立模拟设备会话 |
| `Simulation/TaskMonitorExample.cs` | 纯内存演示任务和工位 |
| `Views/TaskMonitorView.xaml` | 工位表、步骤树和详情页面布局 |
| `Views/TaskMonitorView.*Details.cs` | 按动作类型展示参数、采样和页面关联 |
| `Views/TaskSimulationWindow.xaml.cs` | 内存示例的复位、启动、暂停及安全关闭 |
| `Localization/Strings.*.xaml` | 任务页面中英文资源 |

页面控件构造检查在 `tools/MotionControl.TaskMonitor.Checks`。该检查不代替实际屏幕验收。
