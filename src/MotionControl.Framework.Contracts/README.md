# Framework.Contracts

框架、设备项目和适配器之间的稳定契约边界。只放必要的接口与数据类型，不引用 WPF、厂商 DLL 或具体通讯实现。

按功能分区，初期主要目录如下：

- `Motion`：一张运动卡的连接状态、逻辑轴、轴状态、运动参数和轴操作。
- `IO`：按逻辑名称读 DI、读 DO、写 DO。逻辑名称到卡或远程 IO 物理点位的映射来自设备硬件配置。
- `Flow`、`Alarms`、`Configuration`、`Diagnostics`、`Traceability`：后续按设备运行层实际需要逐项定义。

轴位置与速度使用轴配置所选的工程单位：直线轴用 mm，旋转轴用度。运动卡适配器负责脉冲与工程单位换算。普通受控停止属于轴操作；急停由独立安全回路处理，不通过普通流程接口代替。

契约保持小而直白：流程代码使用逻辑轴和 DI/DO 名称；具体卡号、轴通道、回零和物理 IO 地址留在设备硬件配置及适配器中。
