# Equipment Communications

这里放设备项目自己的通讯定义和交互逻辑。

- PLC 点位按名称和数据类型定义；设备流程所需的命令、应答、握手和超时处理放在 PLC 子目录。
- 视觉、扫码器或其他设备使用自定义 TCP 报文时，按设备或协议名称分开组织。
- 设备通讯地址和连接参数由设备配置提供；通讯代码使用这些配置，不在流程步骤里写 IP、端口或寄存器地址。
- 可复用的 Modbus/TCP 连接和基础读写在 `Adapters/Communications`；工厂 MES 报文放在 `Adapters/Mes`。

PLC 位信号、运动卡 DI/DO 和自定义 TCP 请求不是同一种点位，不把它们合并成一个万能信号管理器。
