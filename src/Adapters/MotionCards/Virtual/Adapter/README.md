# 软件控制卡适配器

此目录将框架运动卡、逻辑 IO 和物理 IO 接口转换为本机独立控制器的 TCP 请求。Host 按工程配置选择适配器，并传入 Machine01 已有的轴、输入、输出映射；设备流程无需直接调用本协议。

控制器监听本机 127.0.0.1，默认端口 18520，连接时严格校验控制器身份和协议版本 2。适配器取得独占租约并每 500 毫秒续约；Host 意外退出、通信失败或命令应答丢失时，控制器约 2 秒后独立停止轴运动。租约过期不会自动改变 DO 电平；操作员应检查输出和设备状态。连接建立前若旧租约仍有效，不允许抢占。每次调用发送一行 UTF-8 JSON 并读取一行响应；控制器明确拒绝时抛出包含命令名称的异常，通信失败不报告假成功。多个 IO 可批量读取。输入输出逻辑极性由设备映射决定，反馈来自控制器独立输入状态，不从输出状态推断。

轴定位使用工程单位，按实际配置的软件限位检查目标，并在停止且位置进入容差后才返回。软件回零固定返回零位，若零位不在启用的软件限位内则拒绝回零。控制器尚不支持点动时自动检查软件限位，因此已启用软件限位的轴会拒绝连续点动。运动取消或等待失败时请求控制器停车；如果停车失败，两个异常都会向调用方报告。当前控制器使用恒速位置插值，尚不模拟加减速曲线、负载、编码器偏差或真实控制器的停止动力学。回零是软件状态模型，不证明原点传感器接线和真实回零动作正确。

日常软件流程验证可选用此适配器。它不会调用正运动原厂 DLL，不验证正运动 SDK、硬件急停和现场设备；这些项目仍需用各自的后端或现场设备验证。
