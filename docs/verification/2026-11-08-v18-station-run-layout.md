# V1.8 工位运行页对照与沙盒验证

## 范围与处理

依据《运动控制框架_现场交互与配置应用手册_V1.8_源码对照与24轴应用_20261107.pdf》第 561—564 页，对正式 Host 的任务列表和 C# 工位两种入口进行对照。手册中的名称、数量及运行数值是布局示意，不当作本次设备状态。

- 任务列表入口改为宽屏工位、步骤和详情三栏；步骤树按层级缩进，名称与状态列不再挤占。工位卡片继续显示当前快照提供的动作、等待和异常摘要，长文字保留完整提示。
- 窄屏用工位选择栏显示真实工位状态及摘要，步骤和详情上下排列；工作区、步骤树及详情可滚动，避免长任务挤掉详情或短窗口只剩表头。切换工位沿用同一个工位对象和原有选择、跟随、定位逻辑。
- C# 入口采用相同阅读顺序，仅显示项目接口实际提供的当前步骤和详情，不构造任务步骤树。工位已提供独立状态时按工位状态标注步骤，未提供时不把整机运行推断为工位正在执行；暂停与停止保留步骤分别标识。读取失败和断连不沿用旧结果或开放输入定位。
- 任务执行来源明确为已读取的任务列表，不暴露内部路径或编造版本、会话标识。期望条件标识为定义，执行采样另行显示；工程范围的投影诊断收进标明范围的折叠区。隐藏内部路径时仍保留可滚动的故障和资源核查提示。
- 补齐 C# 流程页停止状态的中英文资源，避免停止后刷新页面因缺少资源报错。移除 C# 工位页会返回自身的“查看任务运行”入口。

## 验证与限制

- 在独立工作树构建 Release；沙盒运行 60 组操作页内部检查，包含宽窄布局、长步骤、工位选择、隐藏路径时的故障提示、C# 已完成/暂停/停止/读取失败、断连和工程诊断范围。内部状态注入仅用于隔离的内存检查，不代表现场设备状态。
- 使用沙盒内正式 Host，通过正常接口连接独立软件控制器和隔离的十三轴配置；任务入口从界面读取真实配置。C# 入口在另一份隔离配置中选择 `StationFlows`，使用设备示例实际提供的工位与步骤；没有填入手册里的示意数据。
- 宽屏下实际选择工位及嵌套步骤：人工点击步骤后“跟随执行”关闭，切换工位后恢复；窄屏实际展开工位列表、切换工位并滚动查看详情，再恢复宽屏时保留工位选择。工程诊断展开并滚动到底后等待 2 秒，滚动位置仍为 100%，展开状态保留。
- 截图和脚本保存在未跟踪的 `tmp/v18-station-ui-20261108/results/`。`01-task-before.png`、`02-csharp-before.png` 为基线；`20-task-final-wide.png`、`21-task-project-diagnostics.png`、`22-task-final-narrow.png`、`23-task-final-narrow-details.png`、`24-task-final-restored-wide.png`、`25-csharp-final-wide.png`、`26-csharp-final-narrow.png` 为本轮候选代码实测。
- 本轮没有发送轴运动或输出写入命令；切换任务与 C# 入口前从软件控制器接口核对 13 轴停止、14 个映射输出均不活动。
- 本轮界面主要处于等待复位、任务尚未进入执行的状态；真正的生产运行、暂停、停止、设备报警及恢复仍需在软件控制器的完整流程中继续验证。内部内存检查不能代替这些正式 Host 场景，更不能代表真机、安全回路或其他驱动厂商已验证。
- 顶部与左侧外壳、底栏及已验收的轴映射、IO 映射、轴手动、IO 监控页面未改动。约 1050 × 800 窄窗口的顶部设备状态仍有裁切，属于受保护外壳，单独保留待处理。
