- 总览、流程状态、报警、任务配置之间的主要导航均能在正式 Host 中实际走通。

- 步骤中的 DI 可直接定位到逻辑 IO 映射，返回后保留所选步骤和报警关联。
- 一条等待条件支持关联多条报警，列表显示关联数量和停机/非停机类别。
- 当前报警页没有报警时显示 0 条和清晰空状态；刷新不是复位或清除入口。
