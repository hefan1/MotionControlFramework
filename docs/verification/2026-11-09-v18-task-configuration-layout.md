# V1.8 任务配置页对照与沙盒验证

## 范围与处理

依据《运动控制框架_现场交互与配置应用手册_V1.8_源码对照与24轴应用_20261107.pdf》第 319 页的目标布局，对照正式上位机的任务配置页。手册的设备、工位和数据是示意，本次以隔离测试配置和实际接口返回为准。

- 宽屏将工位列表和选中工位的草稿设置并列；窄屏上下排列并分别滚动，在编辑区域保留所选工位名称和稳定标识。设备公共设置、来源及设备工位详情可以展开，长状态区有高度上限，工具栏与表单仍可到达。
- 分开显示当前编辑、已载入任务文件快照和当前运行会话。会话版本、标识及加载时间未提供时明确标为未提供；文件快照与当前文件的一致性未经确认时不声称一致或过期。草稿基准异常与文件快照、当前会话分别说明。
- 任务库搜索不再误记为草稿修改；筛选隐藏当前任务时，复制、编辑和引用操作不能对看不见的目标执行，恢复筛选后按真实任务标识恢复选择。
- 输入无效时保留当前工位和输入。保存结果、新错误和长错误的开头会显示在状态视口内；普通表单输入不强行改变人员的滚动位置。
- 准备配置或其他任务来源无法读取时，保留异常及实际文件路径，旧检查失效，更新、同步和重新载入入口按状态闭锁；重复检查失败不会解除闭锁，同步或重载前再次核查完整来源。读取恢复且字节未变时提示读取恢复，不断言文件发生变化。
- 未修改顶部、左导航、底栏和已验收的轴映射、IO 映射、轴手动、IO 监控页面。

## 验证证据

- 独立工作树的解决方案 Release 构建为 0 警告、0 错误；在沙盒内运行操作页内部检查 62 组和任务编辑内部检查 25 组，均为 0 失败。这些检查使用独立临时配置和内存服务，不能代替正式屏幕或真机验收。
- 使用 Windows Sandbox 内的正式 Host、隔离的十三轴测试配置和独立软件控制器，通过正常界面、配置存储与控制器接口检查；没有连接实机，也没有发送轴运动或输出写入。切换 Host 前从接口核对十三轴停止、十四个映射输出不活动。
- 修改前截图 `29-task-config-baseline.png`；宽窄界面及任务库、设置、来源详情截图为 `30-task-config-candidate-wide.png` 至 `39-task-config-expanded-narrow.png`。真实搜索 `ClipPress` 后，列表显示 2/19 项且草稿仍为无待保存编辑；隐藏选择时编辑入口禁用，重新选择后恢复。
- 在隔离副本中将周期填为无效值并尝试切换工位，界面给出整数错误并保留原输入和工位；恢复原值后使用“保存并检查”。候选界面窄屏结果见 `43-task-config-narrow-invalid.png`、`44-task-config-narrow-saved.png`。保存前后对 19 个任务文件和 `TaskMachine.json` 的 20 项 SHA-256 逐一比较，没有变化；保存的是沙盒草稿，不等于更新文件或加载运行会话。
