# 任务编辑第二轮验证记录

## 本轮范围

只完善已存在的任务编辑、草稿存储和页面操作。没有更改厂商原生 API、传统工位流程或原有轴/IO/设备变量页的布局。默认使用临时目录和内存设备，不连接运动控制器，不发送伺服、运动或 IO 指令。

## 故障与修正

- 对象目录按大小写无关比较，但下拉框原先使用大小写敏感的 `SelectedItem`。现在能选中并保留不同大小写的既有引用，不把它们误清空，也不因查看而改写拼写。
- 组合条件打开时原先会对空条件自动加一个比较条件。现在原样展示空条件，由校验器提示；取反条件删除唯一子条件后可以重新添加，且最多添加一个。
- 保存和语言切换原先会把工位重置到首行。现在按稳定 ID 恢复工位和任务选择。
- 写文件锁不能防止两个窗口先后覆盖同一份草稿。现在按载入/保存时的实际字节签名拒绝旧窗口保存或应用；失败不改变最近保存时间。
- 发生冲突时，可保存本窗口完整副本到独立 Backups 文件；编辑器当前有效输入包含在副本内，不修改原工作区、公共草稿或运行文件。返回后可确认载入最新草稿，不删除他人版本。
- 无效变量值来源原先可能先修改变量名或任务名。现在先解析有效字段，失败时保持模型原值和人员输入。
- 恢复上次应用在确认后再次核对 Host 会话边界；读取草稿及目录失败时保留原窗口内容。

- 任务引擎检查：定义与存储 22 组、纯软件执行 53 组、设备级调度 12 组通过；执行后核心仍无 WPF、Host 或厂商依赖。

- 共 103 组内部检查通过，不等于实际屏幕或设备验收。整份解决方案先前的模板长路径聚合构建问题未纳入本轮修复。
