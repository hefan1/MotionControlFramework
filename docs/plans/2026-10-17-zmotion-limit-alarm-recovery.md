# 正运动限位报警恢复实现计划

**目标：** 让正运动轴复位区分仍然有效的限位、总线驱动器报警和已锁存的历史停止原因，并防止异常轴进入自动流程。

**结构：** 在通用轴状态中记录正运动历史停止原因和限位恢复后的回零要求；在正运动适配器内读取实时状态，阻止限位或报警输入仍有效时复位，按需清除总线驱动器报警，再用 `DATUM(0)` 清控制器错误状态并清除、复核 `AXIS_STOPREASON`。硬限位原因恢复后，禁止该轴定位及整机自动启动，直到该轴重新回零。

**技术：** .NET Framework 4.8、C# 7.3、正运动 `zauxdll.dll` PC API。

## 实施步骤

1. 扩展 `AxisStatus`，记录硬/软限位、当前报警和历史停止原因，并修正正运动状态位解释。
2. 完善 `ZMotionCard`：点动不允许继续进入当前有效限位，限位恢复点动速度受 `HomeCreepSpeed` 限制；复位先确认轴停稳，拒绝仍有效的限位/报警输入，按需清总线驱动报警，再清控制器状态和历史原因并复核。
3. 硬限位原因清除后标记该轴需重新回零；轴定位和整机流程启动在完成回零前保持禁止。整机启动前逐轴读取状态并拒绝当前报警或限位。
4. 更新正运动适配器说明，编译解决方案并审查差异；不打断当前 ZDevelop 仿真会话做运行测试。
