# 轴手动卡片关联 IO 实施计划

## 目标

在轴手动卡片中按轴关联 IO 映射页已有的逻辑 DI/DO。DI 显示实时逻辑状态；DO 显示控制卡报告的逻辑输出状态，并允许使用可配置的按钮文字写入逻辑 ON/OFF。

## 实施步骤

1. 新增按设备保存的 `Parameters/ManualAxisIoAssociations.json` 配置模型，按控制卡编号和物理轴号分组；保留位置配置文件不变。
2. 在轴卡增加关联 IO 的添加、编辑、删除和状态显示。选择项来自已命名的 DI/DO 映射；DO 配置分别填写逻辑 ON/OFF 按钮名称。
3. 使用 `ILogicalIo` 读写逻辑名称，并经 `MachineRuntime.RunManualOperationAsync` 检查手动联锁。读取失败或映射失效时明确显示错误并禁用写操作。
4. 将当前设备映射和逻辑 IO 服务从 Host 传入轴手动页，为新增界面文字补充中英文资源。
5. 构建 Host，查看实际运行页面与关联设置对话框；验证时不写 DO、不触发轴运动。检查改动并只提交本功能涉及文件。

## 验收

- 初始没有关联配置时，轴卡不显示多余的 IO 行。
- 能选择已命名 DI/DO；DI 只读，DO 的 ON/OFF 按钮调用逻辑 IO 服务。
- 每个轴的关联独立保存，重启后可恢复；旧位置配置不迁移、不修改。
- 未通过运行时联锁时 DO 操作被拒绝；状态读取失败不会伪装为 OFF。
- Debug Host 构建成功，并对实际运行页面完成屏幕核对。
