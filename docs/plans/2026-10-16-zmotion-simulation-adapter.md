# 正运动 ZDevelop 仿真适配器实现计划

**目标：** 在独立的正运动适配器项目中接入 ZDevelop 的 `VPLC5xx-Simu`，让现有运动卡、逻辑轴和逻辑 DI/DO 契约有一套可读的厂商实现。

**结构：** 适配器引用 `MotionControl.Framework.Contracts` 与现有 `MotionControl.VendorApi.ZMotion`。一张正运动控制器对象维护一个 SDK 句柄，提供轴列表及逻辑 IO；每个逻辑轴由单独的 `ZMotionAxis` 实现。连接后核对控制器身份，只允许本机仿真地址与仿真器型号；轴参数显式应用，避免只建立连接就改写控制器参数。

**技术：** .NET Framework 4.8、C# 7.3、WPF Host 不在本阶段修改。配置样例放在正运动适配器目录；厂商原生 DLL 不复制进仓库，部署时由用户提供与运行位数匹配的正运动 SDK 文件。

## 范围

- 实现仿真连接、身份读取、轴状态、使能、点动、单轴移动、受控停止、报警清除与逻辑 DI/DO。
- 仿真回零仅将指令坐标清零，不调用实体原点回零流程。
- 只支持 `127.0.0.1` 与 `VPLC5xx-Simu`。实体卡型号和连接方式未知，暂不启用实卡连接。
- 不修改 Host 主窗口，不实现手动调试 UI，不改通用 Contracts，不加入动态插件或通用驱动基类。
- 不新增自动化测试或连接用户当前仿真软件。

## 实施步骤

1. 新增正运动适配器项目、仿真配置类型和清晰的示例 JSON。
2. 实现卡连接、身份核对、轴映射、显式轴参数应用和连接错误处理。
3. 实现逻辑轴的基础运动、状态读取、停止与仿真坐标清零。
4. 在同一控制器实例上实现单点逻辑 DI/DO 映射，并串行保护共享 SDK 句柄。
5. 将适配器加入解决方案，更新项目说明，明确 native DLL 部署和当前未验证范围。

本次按用户要求不运行测试或构建；后续由用户在本机启动 ZDevelop 后进行实际联调。
