# IO 映射保存热更新实施计划

## 目标

保存 IO 映射后，在当前运动控制卡连接内替换逻辑 DI/DO 名称映射，不断开或重建卡对象，不重置轴回零状态。映射应用前确认已映射轴全部停止；完成后刷新手动轴/IO 页面和安全联锁页中的 DI 名称。

## 实施步骤

1. 在卡连接接口增加明确的 IO 映射应用方法，由当前厂商连接实现负责验证并替换运行时映射。
2. 保存页持久化新配置后应用到当前连接；应用失败时恢复之前的配置文件，并移除重连确认弹窗。
3. 正运动卡在原生锁内原子替换 DI/DO 名称表，读写 IO 时在同一锁内查找当前映射。
4. Host 不重建 MachineRuntime；只刷新急停输入绑定、安全 DI 选项和手动调试视图。
5. 编译 Host 并检查改动，只提交本功能文件。

## 验收

- 保存 IO 映射不会调用断开、重连或重新应用轴参数。
- 任一已映射轴正在运动时拒绝应用，配置文件保持原样。
- 热更新后 DI/DO 名称立即可读写，安全配置的急停 DI 立即生效。
- 编译成功；运行页面检查仅在 Host 窗口可访问时报告为完成。
