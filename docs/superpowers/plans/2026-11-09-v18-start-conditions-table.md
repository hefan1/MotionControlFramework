# V1.8 UI-05：启动条件只读表格实施计划

**依据：** UI 交接 PDF 的 UI-05，V1.8 手册第 541 页。

**目标：** 将现有部分内存观察按条件、观察结果、设备采样时间和来源分列，并保留选择详情与原有导航。现有来源没有提供设备采样时间时显示“未提供”；界面观察时间仍单独标注，不能当作设备采样或整机启动许可。

1. 在 `StartConditionsObservationChecks` 中检查中英文列标题、空连接与真实内存来源、设备采样时间“未提供”、稳定选择和不会触发设备操作；先在沙盒复现缺少列的失败。
2. 修改 `EquipmentPreparationView.xaml` 和 `EquipmentPreparationView.StartConditions.cs`，用有界列的只读列表展示现有观察；只在设备真正提供采样时间时才能填入真实时间。切换语言和刷新状态时更新行而不重建集合。
3. 保持覆盖不完整、非原子快照和启动时原门禁检查的提示，关联跳转继续复核连接会话及配置代次。
4. 在沙盒执行操作员页面检查并查看正式 Host 界面；核对窄屏、长原因和滚动，记录截图与未覆盖的真实设备范围，然后中文提交本地 Git。
