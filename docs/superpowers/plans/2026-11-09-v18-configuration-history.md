# V1.8 UI-03：配置变更记录接入计划

**依据：** V1.8 UI 交接 PDF 的 UI-03、手册第 98 页。

**目标：** 在现有 `ConfigurationChangeJournal` 中增加任务草稿/文件、变量定义和报警库保存入口产生的真实阶段回执；设备工程历史页显示对象和阶段。每个阶段单独记录结果，不推断操作者、现场生效版本、字段差异或后续载入。

1. 先在隔离工程中为各保存入口编写成功、失败/拒绝及记录目录故障检查，确认缺少记录时测试失败。保存文件成功而记录失败必须单独向页面报告，不能回滚或把成功文件误报为保存失败。
2. 分别在任务工作区、变量定义和报警库的明确保存调用处接入同一设备记录目录；任务草稿保存、文件更新与后续会话载入是不同阶段。已存在的目录、物理映射及设备运行门禁保持不变。
3. 在设备工程历史列表显示对象、阶段和结果；未接入的其他配置入口明确保留在范围说明中。历史写入失败、读取失败或记录不完整须保留原因。
4. 构建并在 Windows Sandbox 的独立软件仿真项目执行隔离测试及正式 Host 页核对，保留截图和中文验证记录；不触碰真实项目配置。
